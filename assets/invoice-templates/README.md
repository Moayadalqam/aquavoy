# Invoice Templates

Tagged `.docx` templates for Aquavoy M6 Phase 3 invoice generation.
Generated by `scripts/build-invoice-templates.ts` via `pizzip` + OOXML.

## Files

| File | Company | Structure |
|------|---------|-----------|
| `gefo.docx` | Gefo Gesellschaft für Oeltransporte MBH | **Transportation invoice** (voyage freight) |
| `novo-porto.docx` | Novo Porto Scheepvaart BV | Crewing-services sales invoice |

## Token sets (single-brace — docxtemplater default)

### Shared tokens

| Token | Description | Example |
|-------|-------------|---------|
| `{recipient_name}` | Recipient company name | Gefo gesellschaft für oeltransporte MBH |
| `{recipient_address}` | Recipient full address | Raboisen 5 20095 Hamburg |
| `{recipient_vat}` | Recipient VAT number | DE118512502 |
| `{invoice_date}` | Invoice date DD-MM-YYYY | 06-01-2026 |
| `{invoice_number}` | Aquavoy's own number YY-NNN | 26-001 |
| `{vessel}` | Vessel name (template adds "Mts ") | Aqua Donna |
| `{total}` | Total amount (display format) | 35.967,28 |

### Transport tokens (`gefo.docx` only)

## Source structure

- `gefo.docx` — modelled on the client's REAL invoice
  **"26-001 Invoice Aquavoy - Gefo 06-01-2026 voyage 01"** (received from Wency
  2026-07-02), which re-invoices GEFO Gutschrift `26400013`. Issuer block is
  **Aquavoy Shipping Ltd.** (V.A.T CY60038875Q, Registration Number HE 454167);
  body is Barge / Product / Loading port / Discharge port / Quantity × Price per
  ton / Commission % / **VAT REVERSE CHARGED BY RECIPIENT** / Total; footer is
  Revolut IBAN + BIC + Admin@aquavoy.com.
- `novo-porto.docx` — modelled on invoice
  `26-047 … Novo Porto Scheepvaart BV 27-05-2026.pdf` (OneDrive discovery,
  `.planning/m6-onedrive-discovery.md`). Issuer block is **Aquavoy Ltd**; line
  items are Crewing Services / Travel Cost / Service Fee / Cash advance /
  VAT Shifted / Total; footer adds "Payment term: 7 days".

### Gutschrift → invoice mapping (Gefo)

| Gutschrift field | Invoice token | Rule |
|---|---|---|
| Schiff `AQUA-DONNA` | `{vessel}` | title-case, no hyphen → `Aqua Donna` |
| Produkt | `{product}` | verbatim |
| Ladehafen `Amsterdam, Eurotank` | `{load_port}` | reorder → `Eurotank Amsterdam` |
| Löschhafen `Hamburg, Evos` | `{discharge_port}` | reorder → `Evos Hamburg` |
| Fracht `1.062 t` | `{tonnage}` | German integer → `1062` |
| `35,65 €/t` | `{price_per_ton}` | verbatim `35,65` |
| Fracht amount | `{freight_amount}` | verbatim `37.860,30` |
| Bereederungskommission | `{commission_pct}` + `{commission_amount}` | `5` + `-1.893,02` |
| Endbetrag | `{total}` | verbatim `35.967,28` |
| Datum | `{invoice_date}` | `DD.MM.YYYY` → `DD-MM-YYYY` |
| Belegnummer / Referenz | — | **never** the invoice number; Aquavoy assigns its own YY-NNN |

## Regenerating templates

```bash
npx tsx scripts/build-invoice-templates.ts
```

The script writes both `.docx` files and performs a docxtemplater render-test with
sample data (the real 26-001 values) before exiting. If any `{tag}` is malformed,
the script throws before writing (fail-fast).

## Engine

- `docxtemplater` `^3.69.0` — template fill (single-brace `{tag}` delimiters, `paragraphLoop: true`, `linebreaks: true`)
- `pizzip` `^3.2.0` — OOXML zip assembly / reading
- OOXML minimal document: `[Content_Types].xml`, `_rels/.rels`, `word/document.xml`, `word/_rels/document.xml.rels`
